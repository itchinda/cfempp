\doxysubsection{Detailed Description}
RAII wrapper around PETSc Vec. 

\DoxyHorRuler{0}


This class manages the lifetime of a distributed PETSc vector. It follows PETSc ownership semantics and must be used collectively on PETSC\+\_\+\+COMM\+\_\+\+WORLD.

Copying is disabled to prevent double-\/free; move semantics are supported.

Typical usage\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\mbox{\hyperlink{classPetscVector}{PetscVector}}\ x(PETSC\_DECIDE,\ n);}
\DoxyCodeLine{x.setAll(0.0);}
\DoxyCodeLine{x.assemble();}

\end{DoxyCode}
