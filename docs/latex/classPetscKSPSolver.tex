\doxysubsection{Detailed Description}
RAII wrapper for PETSc KSP linear solvers. 

\DoxyHorRuler{0}


Supports optional prefix-\/based configuration through the PETSc options database, enabling runtime configuration via command-\/line or programmatic injection.

Example\+:

{\footnotesize\ttfamily KSPConverged\+Reason Petsc\+KSPSolver\+::get\+Converged\+Reason (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption}) const}



Return the reason why the last KSP solve terminated. 

\DoxyHorRuler{0}
 

This method queries PETSc for the convergence status of the most recent call to \doxylink{classPetscKSPSolver_a78f73216e8d622c582ce563271f89903}{solve()}. The returned value indicates whether the solver\+:
\begin{DoxyItemize}
\item converged successfully,
\item diverged,
\item or stopped for another reason (e.\+g., iteration limit).
\end{DoxyItemize}

PETSc convention\+:
\begin{DoxyItemize}
\item reason \texorpdfstring{$>$}{>} 0 \+: solver converged
\item reason = 0 \+: solver is still iterating (unlikely after \doxylink{classPetscKSPSolver_a78f73216e8d622c582ce563271f89903}{solve()})
\item reason \texorpdfstring{$<$}{<} 0 \+: solver diverged
\end{DoxyItemize}

\begin{DoxyNote}{Note}
This method must be called after \doxylink{classPetscKSPSolver_a78f73216e8d622c582ce563271f89903}{solve()}.
\end{DoxyNote}
\begin{DoxyReturn}{Returns}
KSPConverged\+Reason Enumeration describing the convergence outcome. 
\end{DoxyReturn}

{\footnotesize\ttfamily Petsc\+Real Petsc\+KSPSolver\+::get\+Residual\+Norm (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption}) const}



Return the final residual norm from the last KSP solve. 

\DoxyHorRuler{0}
 

This method returns the norm of the residual associated with the most recent call to \doxylink{classPetscKSPSolver_a78f73216e8d622c582ce563271f89903}{solve()}. The exact definition of the residual (preconditioned or unpreconditioned) depends on the KSP type and solver configuration.

\begin{DoxyNote}{Note}
This value is only valid after a call to \doxylink{classPetscKSPSolver_a78f73216e8d622c582ce563271f89903}{solve()}. 

The norm returned here is the internally monitored norm used by PETSc for convergence testing.
\end{DoxyNote}

Petsc\+Real Final residual norm. 
\end{DoxyReturn}
