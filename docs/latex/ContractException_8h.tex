\doxysubsection{Detailed Description}
Contract-\/based exception hierarchy for error handling. 

This file defines a hierarchy of exception classes used to implement Design by Contract (DbC) in the CFEM framework.

The purpose of this system is to\+:
\begin{DoxyItemize}
\item Enforce preconditions, postconditions, and invariants
\item Detect logical programming errors
\item Provide detailed diagnostic information
\item Improve robustness and maintainability
\end{DoxyItemize}

In release mode (NDEBUG defined), all contract checks are disabled.

This design is inspired by\+: Horstmann, "{}\+Mastering Object-\/\+Oriented Design in C++"{}
