\item \#\#\# MESH ARCHITECTURE \& ENTITY STRATEGY This parser implements a strict decoupling between geometric data and computational semantics using a dual-\/layer entity system\+:
\item \#\#\#\# 1. Mandatory "{}\+Universe"{} Domain (ID -\/1)
\item The solver requires a Physical Group named \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}"{}\+Universe"{}\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*} in the .msh file.
\item This entity must match the maximum dimension of the mesh (e.\+g., 3D for volumes).
\item {\bfseries{Filtering\+:}} Elements not belonging to any Physical Group are ignored to ensure a clean computational domain.
\item \#\#\#\# 2. Automated System Boundary (ID -\/2)
\item After topological reconstruction ({\ttfamily build\+Mesh}), the parser identifies all facets without neighbors (exterior faces).
\item These facets are automatically stored in the \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}"{}\+SYS\+\_\+\+BOUNDARY"{}\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*} entity.
\item This ensures boundary coverage even if the user fails to tag surfaces in Gmsh.
\item \#\#\#\# 3. User-\/\+Defined Entities (ID \texorpdfstring{$>$}{>} 0)
\item Other Physical Groups (e.\+g., "{}\+Inlet"{}, "{}\+Steel\+\_\+\+Region"{}) are mapped to positive internal IDs.
\item {\bfseries{Robust Matching\+:}} Uses a "{}\+Corner-\/only"{} vertex intersection logic. A facet is assigned to a group only if its primary geometric vertices (corners) are tagged, making it immune to diagonal flips or mismatched mid-\/side nodes in quadratic meshes.
\item \#\#\# OPTIMIZATION TECHNIQUES
\item {\bfseries{Tag Interning\+:}} Multiple physical tags per element are reduced to a single integer index ({\ttfamily tag\+\_\+list\+\_\+id}) pointing to a persistent table in the \doxylink{classMesh}{Mesh} class.
\item {\bfseries{\doxylink{structVertex}{Vertex} Harvesting\+:}} Each entity collects and unique-\/ifies its member vertices via a {\ttfamily finalize()} call, providing O(1) access to Do\+Fs for Dirichlet conditions.
\item {\bfseries{Memory Reservation\+:}} Pre-\/allocates vectors for nodes and elements based on Gmsh block headers to minimize reallocations.
