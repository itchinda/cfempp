\doxysubsection{Detailed Description}
Base class for all contract violations. 

This class stores detailed information about a violated contract, including\+:
\begin{DoxyItemize}
\item Source file name
\item Line number
\item Failed logical expression
\item Descriptive error message
\end{DoxyItemize}

It derives from std\+::logic\+\_\+error since contract violations represent programming errors rather than runtime failures.
