\doxysubsection{Detailed Description}
RAII wrapper around PETSc Mat. 

\DoxyHorRuler{0}


This class manages the lifetime of a distributed PETSc Matrix. It follows PETSc ownership semantics and must be used collectively on PETSC\+\_\+\+COMM\+\_\+\+WORLD.

Copying is disabled to prevent double-\/free; move semantics are supported.

Typical usage\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{PetscInt\ n\ \{10\};}
\DoxyCodeLine{\mbox{\hyperlink{classPetscMatrix}{PetscMatrix}}\ A(PETSC\_DECIDE,\ n);}
\DoxyCodeLine{A.preallocate(3,3)}
\DoxyCodeLine{PetscInt\ rstart,\ rend;}
\DoxyCodeLine{MatGetOwnershipRange(A.getRaw(),\ \&rstart,\ \&rend);}
\DoxyCodeLine{\textcolor{keywordflow}{for}\ (PetscInt\ i\ =\ rstart;\ i\ <\ rend;\ ++i)}
\DoxyCodeLine{\ \ \ \ \ A.setValue(i,\ i,\ 2.0);}
\DoxyCodeLine{\ \ \ \ \ \textcolor{keywordflow}{if}\ (i>0)\ A.setValue(i,\ i-\/1,\ -\/1.0);}
\DoxyCodeLine{\ \ \ \ \ \textcolor{keywordflow}{if}\ (i<n-\/1)\ A.setValue(i,\ i+1,\ -\/1.0);}
\DoxyCodeLine{A.assemble();}

\end{DoxyCode}
