\doxysubsection{Detailed Description}
Represents a vector or point in 3D Euclidean space. 


\begin{DoxyItemize}
\item This struct provides the basic linear algebra and vector calculus tools required for mesh transformations, Jacobian calculations, and normal extraction. 
\end{DoxyItemize}
