Detailed Description

Base class for all contract violations.

This class stores detailed information about a violated contract, including:

  • Source file name
  • Line number
  • Failed logical expression
  • Descriptive error message

It derives from std::logic_error since contract violations represent programming errors rather than runtime failures.
