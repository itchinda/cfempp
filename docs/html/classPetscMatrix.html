Detailed Description

RAII wrapper around PETSc Mat.

This class manages the lifetime of a distributed PETSc Matrix. It follows PETSc ownership semantics and must be used collectively on PETSC_COMM_WORLD.

Copying is disabled to prevent double-free; move semantics are supported.

Typical usage:

PetscInt n {10};
PetscMatrix A(PETSC_DECIDE, n);
A.preallocate(3,3)
PetscInt rstart, rend;
MatGetOwnershipRange(A.getRaw(), &rstart, &rend);
for (PetscInt i = rstart; i < rend; ++i)
A.setValue(i, i, 2.0);
if (i>0) A.setValue(i, i-1, -1.0);
if (i<n-1) A.setValue(i, i+1, -1.0);
A.assemble();
