Detailed Description

RAII wrapper for PETSc KSP linear solvers.

Supports optional prefix-based configuration through the PETSc options database, enabling runtime configuration via command-line or programmatic injection.

Example:

PetscKSPSolver solver("inner");
solver.addOption("ksp_type", "gmres");
solver.addOption("pc_type", "ilu");
solver.setFromOptions();
solver.setOperators(A);
solver.solve(b, x);

KSPConvergedReason PetscKSPSolver::getConvergedReason ( ) const

Return the reason why the last KSP solve terminated.

This method queries PETSc for the convergence status of the most recent call to solve(). The returned value indicates whether the solver:

  • converged successfully,
  • diverged,
  • or stopped for another reason (e.g., iteration limit).

PETSc convention:

  • reason > 0 : solver converged
  • reason = 0 : solver is still iterating (unlikely after solve())
  • reason < 0 : solver diverged
Note
This method must be called after solve().
Returns
KSPConvergedReason Enumeration describing the convergence outcome.

PetscReal PetscKSPSolver::getResidualNorm ( ) const

Return the final residual norm from the last KSP solve.

This method returns the norm of the residual associated with the most recent call to solve(). The exact definition of the residual (preconditioned or unpreconditioned) depends on the KSP type and solver configuration.

Note
This value is only valid after a call to solve().
The norm returned here is the internally monitored norm used by PETSc for convergence testing.
