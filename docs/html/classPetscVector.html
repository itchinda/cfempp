Detailed Description

RAII wrapper around PETSc Vec.

This class manages the lifetime of a distributed PETSc vector. It follows PETSc ownership semantics and must be used collectively on PETSC_COMM_WORLD.

Copying is disabled to prevent double-free; move semantics are supported.

Typical usage:

PetscVector x(PETSC_DECIDE, n);
x.setAll(0.0);
x.assemble();
