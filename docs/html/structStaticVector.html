Detailed Description

template<typename T, int N>
struct StaticVector< T, N >

A fixed-size column vector of size N.

Template Parameters
TThe numeric type (e.g., CfemReal).
NDimension of the vector.
  • This class is intended for small, element-level algebraic operations (local residuals, shape function values, etc.) where stack allocation and compile-time size checking are critical for performance.
